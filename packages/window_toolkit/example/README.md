# window_toolkit examples

Run individual demos from the package root:

```bash
# Layout
dart run example/layout/hbox.dart
dart run example/layout/align.dart
dart run example/layout/padding.dart
dart run example/layout/wrap.dart
dart run example/layout/row.dart
dart run example/layout/column.dart
dart run example/layout/flex.dart

# Controls
dart run example/controls/checkbox.dart
dart run example/controls/slider.dart
dart run example/controls/card.dart
dart run example/controls/switch.dart
dart run example/controls/radio_button.dart
dart run example/controls/icon_button.dart

# Advanced widgets
dart run example/widgets/scroll_area.dart
dart run example/widgets/text_field.dart
dart run example/widgets/dropdown.dart
dart run example/widgets/list_box.dart
dart run example/widgets/menu.dart
dart run example/widgets/dialog.dart
dart run example/widgets/tabs.dart
dart run example/widgets/tooltip.dart
dart run example/widgets/popup.dart
dart run example/widgets/showcase.dart
```

These demos share reusable scene builders in `example/lib/` and are mirrored by widget tests under `test/examples/`.
